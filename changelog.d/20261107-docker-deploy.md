### Added — CineLight runs in Docker and ships through `./release.sh`

CineLight is now one container image (`ghcr.io/gregochr/cinelight`), built by a tag push and deployed by the self-hosted runner on the host. The settings file lives outside the image in a mounted `/config` directory and is rewritten atomically with its permissions kept, so dashboard changes survive a restart and a failed save never damages the file. `GET /actuator/health` and `/actuator/health/container` are public and show only a status; every other `/actuator` path is denied. `./release.sh` promotes the changelog and tags, `scripts/prod-health.sh` checks the deploy, and `scripts/rollback.sh` restores the previous image and settings. Run in development as before: with no `cinelight.config-file` set, nothing changes.
