### Changed — CineLight now runs on JDK 25 and Spring Boot 4.1

The app is built for JDK 25 with Spring Boot 4.1.2 (Spring Framework 7, Spring Security 7, Jackson 3). The host that runs CineLight must now have JDK 25 installed; JDK 17 will no longer start it. Plex payload handling, the SSE wire format and the dashboard behave as before.
