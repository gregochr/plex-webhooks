### Added — nightly backups of every database in the shared `utils-pg` Postgres server

`ops/utils-pg/backup.sh` dumps each database (CineLight, wainwrights and any added later) at 02:30 London time through a systemd timer, checks every dump with a full `pg_restore` read before it counts, keeps 7 daily and 4 weekly copies per database plus a roles dump, and can copy off the host. `ops/utils-pg/verify.sh` runs daily from GitHub Actions: it checks the installed scripts have not drifted, that each dump is fresh and matches the live database list, and that every dump restores into a throwaway server with at least as many rows as the live database had. Nothing about the data (table names, rows) reaches a log or artifact. A real-Postgres CI job proves both scripts, including that a truncated dump fails them. The scripts are installed by their own workflow, `install-utils-pg-backup.yml`, not by CineLight's deploy.
