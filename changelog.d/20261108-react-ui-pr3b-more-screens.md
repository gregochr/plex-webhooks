### Added — Event monitor, Lighting, Config and Debug screens in the new dashboard

The **More** menu now opens four screens: the Event monitor (the last 100 events with each one's payload, and Simulate
buttons when the Debug tab is enabled), Lighting (Hue and DIRIGERA status, the Hue resources, and Use on start / Use on
stop for a scene), Config (the media type by event matrix, intervals edited in seconds with Save and Cancel, and
credentials shown only as Set / Not set) and Debug (Integrate Hue, show all Hue resource types, Test Hue connection and
Send test event). Each is a link such as `#/config`, so the browser's Back button works.
