Lights. Camera. Automatic.

CineLight automates your Philips Hue lights when you play, pause, or stop movies (or any media) in Plex. Settle in for a better movie night...

Features

Automatically set the scene in Philips Hue lights when starting or stopping your media in Plex
Restore lights when the action stops so you can easily refill your popcorn
Support for all of your lights controlled with Philips Hue
Customisable for films and TV Shows (and Plex's other media types)
Real-time dashboard with a live Plex event monitor and a UI to update configuration
Self-hosted Spring Boot app, so no cloud dependency
Requires Java 25+ · Plex Media Server · Philips Hue Bridge
